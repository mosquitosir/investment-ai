# 架构决策

## 2026-09-20：按用户给出的目录建立分层结构
- app.py：设置网页并调用工作台入口。
- src/ui/workspace.py：工作栏和文档阅读。
- src/ui/quotes.py：行情表格与错误提示。
- src/data/akshare_adapter.py：唯一的 AKShare 接口调用入口。
- src/data/data_manager.py：字段检查和名称整理，不负责页面。
- 指标、筛选器、策略保留占位模块；不引入插件系统、数据库或多数据源自动切换。

原因：让文件职责容易定位，同时保持当前实现简单。
文档选择来自固定白名单，不接受任意文件路径；文档页不触发行情请求。
数据目录仅预留，暂无落盘与缓存逻辑。临时页面状态只保存本次会话行情，以便切换文档后返回查看。
运行环境暂复用旧 C 盘虚拟环境，项目文件在 D 盘；这不等于应用缓存已迁移。
