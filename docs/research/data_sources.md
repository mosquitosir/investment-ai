# 数据源研究

## 2026-09-20 实测记录
| 来源 | 实测结果 | 当前决策 |
|---|---|---|
| AKShare / 东方财富 | 默认代理和临时直连均断开连接 | 暂不使用，未断定具体原因 |
| AKShare / 新浪 | 少量请求 HTTP 200 并返回行情 | 可作后续备选；标准函数未保留所有估值字段 |
| AKShare / 腾讯 | 少量请求和全量接口页面检查均通过 | 当前采用 stock_zh_a_spot_tx() |
| Tushare | 未测试，未接入 | 使用条件、Token、免费范围和权限待官方资料核实 |

腾讯字段映射：code → 股票代码，name → 股票名称，zxj → 最新价，zdf → 涨跌幅。
价格单位元，涨跌幅单位百分比；保留 sh/sz/bj 前缀。非交易时段通常为最近交易行情，不能把页面请求时间当成交时间。

官方参考：https://akshare.akfamily.xyz/data/stock/stock.html
