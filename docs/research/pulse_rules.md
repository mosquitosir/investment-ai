# 资本脉象扫描规则 V0.1

## 范围与单位
只扫描 config/watchlist.yaml 指定的 8 家公司。该文件使用 JSON 兼容的 YAML 写法，标准库即可读取，无需额外 YAML 依赖。
阈值统一在 config/pulse_thresholds.json；研究标签来自用户，不是程序生成的基本面结论。

数据来源优先 AKShare 腾讯历史日线，失败尝试东方财富，再读取有效缓存。
每个网络接口独立进程，最多等待 35 秒，防止整个扫描卡死。失败时保留错误摘要。
采用后复权 OHLC，减少拆股/除权对指标影响；close 是后复权数值而不是当日未复权报价。
成交额元，成交量股，换手率百分数；收益率、振幅、RS、距离高点以小数表示（0.03=3%或3个百分点）。
依赖数据源的复权质量；未来更正或复权因子修订仍可能改变重算历史状态。本版不是历史回测。

## P1–P6
- P1：当天成交额 / shift(1) 后前20行均额，窗口必须20个非缺失值；分母零返回 missing。1.5倍活跃，2倍明显放量。
- P2：收盘价严格超过此前20/60/120交易日最高价才算新高；距离=收盘/此前最高价-1。不是“今日最高价触及即新高”。平台候选=此前20日最高/最低-1≤15%，今日收盘突破其最高且成交额比≥1.2。
- P3：MA5/10/20/60包括当日收盘；MA5>MA10>MA20为短均线多头，另判close>MA60。两种布尔状态任一变化即结构变化。
- P4：当天换手率 / 前20日均换手率，不含当天；缺失不替代，相关分类禁用。
- P5：个股close/20日前close-1，减去同一日期结束的基准20日收益。基准为固定8股每天再平衡等权组合的日收益复合，含股票自身，不是正式行业指数。任一成员当日收益缺失则基准当日缺失，20日窗口不足则RS missing，不偷偷改变成分股。
- P6：按成交额比≥1.5定义放量，<0.8定义缩量；用当天收益方向区分上涨/下跌。放量且上影线/日内高低差≥0.5优先标冲高回落；否则距此前60日高点不低于-3%且收益绝对值≤1%标高位放量滞涨。其余为常态量价。零振幅的影线比例为missing。

所有历史基准只用当日以前的数据，不反向填充。日期先排序、去重并截到允许的截止日。北京时间16点前不纳入当天日线。

## 脉象条件与冲突
至少150日历史；核心成交额比、日收益、MA60或20日波动缺失时 INSUFFICIENT_DATA。
- 沉：成交额比与换手比均<0.8，非短均线多头且未站上MA60。
- 浮：成交额比≥1.5，而短均线多头未连续5日。
- 迟：20日日收益标准差<1.5%，且20日收益绝对值<3%。
- 数：成交额比、成交量比、换手比均≥1.5，日收益≥3%，振幅≥5%。
- 滑：连续5日短均线多头、站上MA60、近20日上涨日均成交额大于下跌日均成交额，距近20日最高收盘回撤≤10%。没有上涨/下跌样本时不强判。
- 涩：P6为放量冲高回落或高位放量滞涨。

多个条件并存为 MIXED，全部不满足为 UNKNOWN。不通过优先级强行覆盖冲突。
单一匹配基础评分0.75，多重匹配0.4，再乘成交额比/换手比/RS/成交量比完整度；陈旧数据再减半。评分不是统计置信概率。

## 脉变与叫醒
用同一规则对前一条交易日和当前日计算状态，保存至 data/cache/pulse_states.csv（代码+日期唯一）。不把上次扫描运行日当上一交易日。首次也可重算昨日；复跑同日不会产生虚假的“昨日=今日”。
有效六态与MIXED之间发生变化才确认脉变；UNKNOWN/INSUFFICIENT_DATA的进出不作为确定脉变。
重点报告：脉变、成交额比≥1.5、换手比≥1.5、任意窗口新高、平台候选、均线结构变化、RS相对上一交易日变化≥3个百分点、冲高回落/高位滞涨。
缺失或陈旧数据单独报告，不能把“没有可算数据”说成“没有异常”。
新鲜度暂以最近工作日作保守参考，未接正式交易日历，节假日/停牌可能标DATA_STALE。缓存回退始终标DATA_STALE并保留原last_update。

## 必须保留的 R01–R07
- R01：高增长≠气足；必须验证组织、技术、客户验证、经营兑现。
- R02：现金流下降≠自动液虚；必须区分生长性耗液与经营性失血。
- R03：存货增长≠自动湿；必须结合订单、验收周期、库存结构、周转和收入兑现。
- R04：利润暴增≠自动补气；必须剥离投资收益、公允价值变动和其他非经常因素。
- R05：估值必须三诊：绝对估值 × 自身历史分位 × 同行横向估值。
- R06：脉强≠体强；资金和价格变化不得覆盖企业基本面诊断。
- R07：脉必须结合“位”解释；低位+体强+沉→滑，与高位+体弱+滑→数意义不同。

V0.1只执行行情之“脉”，R01–R07保存为长期研究约束，尚未自动验证基本面。无买卖建议、无目标价、无LLM API。
