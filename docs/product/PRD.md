# 产品需求 · V0.1

## 使用者与目标
为非专业程序员搭建可理解、可逐步扩展的 A 股筛选工具，先接通真实免费数据，再逐步加入筛选。

## 已确定需求
- Python + AKShare + Streamlit，页面标题为「A股基础策略筛选器 V0.1」。
- 当前采用腾讯行情，前 30 条显示股票代码、名称、最新价、涨跌幅。
- 用户已调整早期 11 字段要求：先跑通，其他字段后续再评估。
- 显示请求失败、空数据和字段变化提示。
- 左侧工作栏集中查询项目文档及行情，不依赖行情请求也能阅读文档。
- 所有新项目产出存放在 D:\chatgpt。

## 本轮不做
数据库、历史回测、自动交易、收费 API、用户 Token、公网部署。

## 验收
文档入口可用；真实接口数据可显示；行情失败不会影响文档查询；占位功能明确标记未开发。
