# 50股资本候诊台 V0.1

本地研究工具：行情层呈现市场事实，诊断层显示已有模型研究结果，两者独立。候诊名单不是投资推荐。

## 启动
Windows 双击本目录 run.bat。会进入正确目录、启动 Streamlit 并打开 http://127.0.0.1:8501 。当前环境暂复用原 C 盘 Python，项目和行情缓存都在 D 盘。已有服务运行时直接打开网址即可，不重复启动。

新电脑安装（建议 Python 3.12，在本项目目录执行）：
```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## 使用
- 首页先读取缓存，点击「刷新行情」批量更新候诊池。
- 左侧按行业筛选；搜索框支持股票名称及6位代码。
- 点击数字表头进行升降序排序；也可用表格上方的排序字段和顺序，确保所有主要数值都可排序。
- 名称在首列，代码次列；上涨红色，下跌绿色。成交额、市值按列标注的单位显示，CSV保留元。
- 点击表格行打开右侧诊断；切换「诊断」查看体、势、脉和触发。
- 「股票管理」中输入一行一个代码或上传含 code 列的 CSV，识别预览后确认加入。可提供 name、notes；本批行业由选择框确认。未识别名称需手动填写。
- 「修改行业、备注 / 移出股票」可调整归类和研究备注。移出是软删除，CSV中保留 REMOVED 记录；重新导入可恢复。
- 数量不限于50，只在首次初始化时导入指定50只。默认十行业的数量来自实际候诊池。

## 数据与降级
UI → MarketDataService → TencentMarketAdapter → AKShare批量行情与腾讯批量快照。
AKShare提供涨速、YTD、PE-TTM；腾讯快照提供交易时间戳、报价、成交、市值、量比、PB和OHLC。无Token、无付费API。
当前价是未复权快照价格，与旧Pulse扫描器的后复权close口径不同，不混用。
交易日期来自源站时间戳，最后更新时间是获取时间；休市不冒充盘中实时。
LIVE：本次从源站获取；CACHED：30分钟内缓存；STALE：较早缓存；MISSING：无报价。
缺少字段记录 missing_fields，显示 --；单只异常不拖垮其余股票；请求失败保留最近缓存。
缓存：data/cache/latest_quotes.csv；候诊池：data/watchlist.csv。

## 诊断范围
沿用 data/pulse_watchlist.csv 的历史研究结果，按股票代码精确匹配并显示诊断日期。
初始50股中5只半导体设备股票有已有脉象，其余待诊。刷新行情不会自动重算脉象。
天时、主证、红旗门、地利八诊、舆情、主要矛盾和复诊条件尚未自动接入，页面保留待诊入口。
今日活跃=量比达到 config/settings.yaml 的阈值；脉变/舆情/风险快捷筛选暂不输出当日结果。

## 验证与限制
运行测试：python -m unittest discover -s tests -v。
配置 YAML 使用 JSON兼容写法，无需新增解析依赖。
旧Pulse扫描器保留，本版本不继续扩展；全A自动选股、Industry Radar、复杂回测、自动交易和LLM决策全部暂停。
免费接口可能变更，字段映射是当前实测口径，不保证未来可用。多窗口同时写同一候诊池暂未加并发锁，请单窗口修改。

### 两个观察池与资金流
左侧“观察池”切换50股资本候诊/高成长跃迁20股，共用行情和刷新逻辑。成长名单位于data/growth_inflection_watchlist.csv，所有阶段待诊，下一验证点为人工研究问题。
“今日净流入”位于涨跌幅后，按原始金额数值排序，缺失--。当前AKShare东方财富资金流请求ProxyError，0只有可用资金流。主力净流入不冒充全口径净流入；净流入率UNKNOWN。详情显示请求时间与源站更新时间（未提供则--），不把两者混淆。
启动：在项目目录执行run.bat；网址http://127.0.0.1:8501/。

### 本机稳定启动

- 直接打开 `open-app.bat`：后台启动服务并打开浏览器。
- 当前 Windows 用户登录后会通过启动目录中的“投资AI候诊台”快捷方式自动运行。
- 自动脚本会先检查 8501 健康状态，已运行时不会重复启动。
- `127.0.0.1` 是本机地址，电脑关机时不可访问；手机公网访问依赖另行完成的云端部署。
## A02｜今日脉动

顶部选择“今日脉动”，可观察两个候诊池去重后的70只股票。点击“刷新并保存快照”会刷新行情、更新未复权日线基线并保存一个5分钟点时快照。页面支持搜索、排序、状态筛选和完整参数详情。

V0.1只做数据、参数、状态和历史积累。当前没有自动交易、上涨概率或目标价。分钟资金流、正式行业指数和Level-2没有可靠来源时明确显示缺失。详细定义见 `docs/research/intraday_pulse.md`。
